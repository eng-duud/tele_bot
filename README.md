# 🚀 منصة المتجر الرقمي متعددة المتاجر عبر تليجرام (White-Label SaaS Telegram E-Commerce Platform)

منصة متجر رقمي SaaS متكاملة ومصممة بمعمارية المؤسسات (Enterprise Architecture) مبنية بواسطة **Django 5** و **aiogram 3** و **Celery** و **PostgreSQL/SQLite** و **Redis**. 

تتميز المنصة بأنها **مهيأة بالكامل بدون أي بيانات ثابتة (Zero Hardcoding)**، ويمكن تخصيص كل تفاصيل المتجر، العلامة التجارية، أسعار الصرف، مكافآت الإحالة، وحسابات الدعم مباشرة من لوحة تحكم المشرف أو لوحة الويب.

---

## 🌟 الميزات والمكونات الجديدة (SaaS & Advanced Features)

### 1. ⚙️ محرك إعدادات المتجر الديناميكي (SaaS Configuration Engine)
- **تخصيص كامل للهوية:** إمكانية تعديل اسم المتجر (`STORE_NAME`)، رسالة الترحيب، وسعر الصرف اللحظي (USD / YER) مباشرة من بوت الإدارة ومن لوحة Django Admin.
- **كاش عالي الأداء:** تخزين الإعدادات في الذاكرة مع نظام تحديث ذكي لتسريع الاستجابة الفورية للمستخدمين.

### 2. 🤝 نظام الإحالات ودعوة الأصدقاء (Affiliate & Referral Engine)
- **روابط إحالة مخصصة:** يحصل كل عميل على رابط دعوة فريد بصيغة `https://t.me/<bot_username>?start=ref_<telegram_id>`.
- **مكافأة مالية فورية:** تودع مكافأة نقدية بالريال اليمني (YER) في محفظة الداعي فور تسجيل العميل الجديد واجتيازه فحص الاشتراك الإجباري.
- **تحكم إداري كامل:** تحديد مبلغ المكافأة بالريال اليمني، وإمكانية تفعيل أو تعطيل نظام الإحالات بضغطة زر من لوحة تحكم المشرفين.
- **منع الازدواج المالي (Idempotency):** معالجة المكافأة مرة واحدة فقط لكل مدعو داخل قفل قاعدة بيانات ذري.

### 3. 🎧 نظام تذاكر الدعم الفني المدمج (Integrated Support Ticketing System)
- **تواصل مباشر + تذاكر داخلية:** يعرض البوت معرف الدعم الفني المحدد ديناميكياً من الإدارة، مع إمكانية كتابة تذكرة داخلية وإرسال استفسار أو لقطة شاشة.
- **بطاقات تفاعلية في مجموعة المشرفين (Admin Group):** يتم توجيه كل تذكرة إلى مجموعة الإدارة مع أزرار تفاعلية: `[✍️ الرد على العميل]` و `[🔒 إغلاق التذكرة]`.
- **رد فوري متعدد الطرق:** يمكن للمشرف الضغط على زر الرد أو استخدام خاصية الرد الافتراضية في تليجرام (Swipe to Reply)، ليصل الرد منسقاً باسم المشرف إلى محادثة العميل الخاصة فورياً.

### 4. 📢 قنوات الاشتراك الإجباري الديناميكية (Dynamic Mandatory Channels)
- إدارة كاملة للقنوات الإجبارية من لوحة الإدارة ومن البوت: إضافة قنوات بروابطها وحذفها فورياً دون الحاجة لتعديل الكود أو إعادة تشغيل الخادم.
- فحص برمجي تلقائي عبر Telegram Bot API لاشتراك العميل قبل منحه الوصول لميزات المتجر.

### 5. 💰 نظام المحفظة المالية ودفتر الأستاذ (Atomic Ledger Wallet)
- دفتر أستاذ محاسبي غير قابل للتعديل المباشر (Immutable Ledger).
- حماية ضد البيع المزدوج باستخدام الأقفال الذرية (`select_for_update`).
- منع تكرار العمليات عبر مفاتيح فريدة (Idempotency Keys).

### 6. 🔐 تشفير البيانات الحساسة (Fernet Encryption)
- تشفير بيانات حسابات المنتجات الفردية وبيانات الاعتماد الخاصة بمزودي الـ API.

## 🛠️ خطوات التشغيل والبدء السريع

### 1. تفعيل البيئة الافتراضية
```powershell
.\venv\Scripts\activate
```

### 2. ضبط ملف البيئة `.env`
قم بفتح ملف `.env` وضع توكنات البوتات ومعرفات التليجرام:
- `CUSTOMER_BOT_TOKEN`: توكن بوت العميل من [@BotFather](https://t.me/BotFather).
- `ADMIN_BOT_TOKEN`: توكن بوت الإدارة من [@BotFather](https://t.me/BotFather).
- `ADMIN_GROUP_ID`: معرف مجموعة المشرفين الخاصة (مثال: `-1001234567890`).
- `SUCCESS_CHANNEL_ID`: معرف قناة العمليات الناجحة (مثال: `@MySuccessChannel`).
- `SUPER_ADMIN_TELEGRAM_ID`: معرف التليجرام الرقمي الخاص بك (ليتم تعيينك مديراً عاماً تلقائياً).

*(ملاحظة: النظام مهيأ حالياً بـ `USE_POSTGRES=False` ليعمل على SQLite مباشرة وبدون إعدادات معقدة في بيئة التطوير، ويمكنك تحويله لـ PostgreSQL في أي وقت بوضع `USE_POSTGRES=True`).*

---

### 3. إنشاء جداول قاعدة البيانات (Migrations)
قم بتشغيل الأوامر التالية لإنشاء كافة الجداول بما فيها نظام الدعم والتذاكر وحقول الإحالات:
```powershell
python manage.py makemigrations
python manage.py migrate
```

---

### 4. تغذية المتجر بالبيانات الأولية الجاهزة (Seed Demo Data)
قم بتشغيل الأمر المخصص لتعبئة طرق الدفع اليمنية الحقيقية (الكريمي، جيب، ون كاش) والأقسام والمنتجات الرقمية والمخزون المشفر:
```powershell
python manage.py seed_demo_data
```

---

### 5. تشغيل البوتات! 🤖

يمكنك تشغيل كلا البوتين (بوت العميل + بوت الإدارة) معاً في نفس الوقت بأمر واحد:
```powershell
python manage.py run_all_bots
```

أو تشغيل كل بوت في نافذة منفصلة إذا رغبت:
```powershell
# لتشغيل بوت العميل فقط:
python manage.py run_customer_bot

# لتشغيل بوت الإدارة فقط:
python manage.py run_admin_bot
```

---

### 6. تشغيل لوحة التحكم الويب (Django Admin)
إذا أردت تصفح وإدارة كافة البيانات وتذاكر الدعم وإعدادات النظام عبر المتصفح:
```powershell
python manage.py createsuperuser
python manage.py runserver
```
ثم توجه إلى: `http://127.0.0.1:8000/admin/`

## 📁 هيكلية تطبيقات المشروع (Modular Monolith)

- `apps/core`: محرك إعدادات النظام (`SystemSettingService`)، أسعار الصرف، التشفير، ودوال المساعدة.
- `apps/support`: نظام تذاكر الدعم الفني، الرسائل المتبادلة، والربط مع مجموعة الإدارة.
- `apps/users`: إدارة حسابات التليجرام، نظام الصلاحيات (RBAC)، ومحرك الإحالات (`ReferralService`).
- `apps/wallet`: المحفظة المالية وسجل دفتر الأستاذ (Ledger Transactions).
- `apps/payments`: طرق الدفع، وطلبات شحن الرصيد والتحقق منها.
- `apps/catalog`: التصنيفات والمنتجات الرقمية والأسعار.
- `apps/inventory`: إدارة المخزون المشفر بأنواعه الأربعة.
- `apps/orders`: إدارة دورة حياة الطلبات والمبيعات.
- `apps/providers`: واجهات مزودي الخدمات الخارجيين مع حماية المفاتيح.
- `apps/fulfillment`: التسليم الآلي للطلبات في الخلفية مع الاسترجاع التلقائي عند الفشل.
- `apps/services_app`: الخدمات الرقمية وعروض الأسعار المخصصة.
- `apps/notifications`: التحقق من القنوات الإجبارية وبث الإيصالات في قناة العمليات الناجحة.
- `apps/audit`: سجل تتبع وتدقيق إجراءات المشرفين.
- `apps/telegram_bot`: محرك معالجة أحداث التليجرام لكلا البوتين ومجموعة الإدارة (aiogram 3).
