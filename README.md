# 🚀 منصة المتجر الرقمي المتكاملة عبر تليجرام (Telegram Digital E-Commerce Platform)

منصة متجر رقمي متكاملة ومصممة بمعمارية المؤسسات (Enterprise Architecture) مبنية بواسطة **Django 5** و **aiogram 3** و **Celery** و **PostgreSQL/SQLite** و **Redis**.

تعتمد المنصة على بوتين تليجرام منفصلين:
1. **بوت العميل (Customer Bot):** واجهة متجر تفاعلية كاملة للشراء، تصفح الأقسام، شحن الرصيد، متابعة الطلبات، والاشتراك الإجباري في القنوات.
2. **بوت الإدارة (Admin Bot):** لوحة تحكم إدارية كاملة لإدارة المنتجات، المخزون، الأسعار، والإحصائيات الحية.
3. **مجموعة الإدارة الخاصة (Admin Group):** استقبال بطاقات شحن الرصيد والمشاكل الفنية مع أزرار مضمنة للموافقة الفورية والآمنة `[✅ قبول]` و `[❌ رفض]`.

---

## 🏗️ المميزات والمعمارية الهندسية

- **نظام مالي ومحفظة مركزية (Ledger Wallet):**
  الرصيد بالريال اليمني (YER) والدولار (USD)، وجميع العمليات المالية مسجلة في دفتر أستاذ محاسبي لا يقبل التعديل المباشر، ومحمي بأقفال ذرية على مستوى الصف (`select_for_update`) لمنع أي تضارب مالي أو بيع مزدوج.
- **منع التكرار الصارم (Idempotency):**
  لو تم الضغط على زر الموافقة على الدفع أو الشراء عدة مرات بالخطأ، لا يتم خصم أو إضافة الرصيد إلا مرة واحدة فقط.
- **تشفير البيانات الحساسة (Fernet Encryption):**
  حسابات ومفاتيح المنتجات الفردية، وأسرار مزودي الـ API مشفرة بالكامل في قاعدة البيانات ولا تظهر كنصوص مكشوفة في السجلات.
- **فصل المهام الثقيلة والتسليم التلقائي (Async Fulfillment):**
  استدعاءات الـ API للمزودين الخارجيين تتم في الخلفية عبر **Celery Workers** خارج الـ Database Transaction مع نظام إعادة المحاولة التلقائي (Exponential Backoff) واسترجاع الرصيد التلقائي للمحفظة في حال الفشل النهائي.
- **اشتراك القنوات الإجباري الفعلي:**
  التحقق البرمجي التلقائي عبر Telegram API من اشتراك المستخدم في القنوات المحددة قبل السماح له بدخول المتجر.
- **قناة العمليات الناجحة:**
  نشر إيصالات عمليات الشراء الناجحة آلياً في قناة عامة مع إخفاء وتشفير أي بيانات شخصية أو حساسة.

## 🛠️ خطوات التشغيل والبدء السريع

### 1. تفعيل البيئة الافتراضية
تأكد من تفعيل البيئة التي أنشأتها مسبقاً:
```powershell
.\venv\Scripts\activate
```

### 2. ضبط ملف البيئة `.env`
قم بفتح ملف `.env` وضع توكنات البوتات ومعرفات التليجرام:
- `CUSTOMER_BOT_TOKEN`: توكن بوت العميل من [@BotFather](https://t.me/BotFather).
- `ADMIN_BOT_TOKEN`: توكن بوت الإدارة من [@BotFather](https://t.me/BotFather).
- `ADMIN_GROUP_ID`: معرف مجموعة المشرفين الخاصة (مثال: `-1001234567890`).
- `SUCCESS_CHANNEL_ID`: معرف قناة العمليات الناجحة (مثال: `@MySuccessChannel`).
- `SUPER_ADMIN_TELEGRAM_ID`: معرف التليجرام الرقمي الخاص بك (ليتم تعيينك مديراً عاماً تلقائياً).

*(ملاحظة: النظام مهيأ حالياً بـ `USE_POSTGRES=False` ليعمل على SQLite مباشرة وبدون إعدادات معقدة في بيئة التطوير، ويمكنك تحويله لـ PostgreSQL في أي وقت بوضع `USE_POSTGRES=True`).*

---

### 3. إنشاء جداول قاعدة البيانات (Migrations)
قم بتشغيل الأوامر التالية لإنشاء كافة الجداول ونظام المحفظة والمخزون:
```powershell
python manage.py makemigrations
python manage.py migrate
```

---

### 4. تغذية المتجر بالبيانات الأولية الجاهزة (Seed Demo Data)
قم بتشغيل الأمر المخصص لتعبئة طرق الدفع اليمنية الحقيقية (الكريمي، جيب، ون كاش) والأقسام والمنتجات الرقمية والمخزون المشفر:
```powershell
python manage.py seed_demo_data
```

---

### 5. تشغيل البوتات! 🤖

يمكنك تشغيل كلا البوتين (بوت العميل + بوت الإدارة) معاً في نفس الوقت بأمر واحد:
```powershell
python manage.py run_all_bots
```

أو تشغيل كل بوت في نافذة منفصلة إذا رغبت:
```powershell
# لتشغيل بوت العميل فقط:
python manage.py run_customer_bot

# لتشغيل بوت الإدارة فقط:
python manage.py run_admin_bot
```

---

### 6. تشغيل لوحة التحكم الويب الاحتياطية (Django Admin - اختياري)
إذا أردت تصفح البيانات عبر المتصفح أيضاً:
```powershell
python manage.py createsuperuser
python manage.py runserver
```
ثم توجه إلى: `http://127.0.0.1:8000/admin/`

## 📁 هيكلية تطبيقات المشروع

- `apps/core`: أسعار الصرف (USD / YER)، دوال التشفير Fernet، والنماذج الأساسية.
- `apps/users`: إدارة مستخدمي التليجرام ونظام الأدوار والصلاحيات (RBAC).
- `apps/wallet`: المحفظة المالية، العمليات الذرية المانعة للازدواج المالي، وسجل الأستاذ.
- `apps/payments`: طرق الدفع الديناميكية، وطلبات شحن الرصيد.
- `apps/catalog`: التصنيفات الهرمية، المنتجات والأسعار بالريال والدولار.
- `apps/inventory`: إدارة المخزون المشفر بأنواعه الأربعة وإشعارات التوفر.
- `apps/orders`: الطلبات، لقطة الأسعار اللحظية، ومحرك دورة حياة الطلب.
- `apps/providers`: واجهات المزودين الخارجيين والمزود التجريبي (Mock Provider).
- `apps/fulfillment`: معالجة التسليم والمهام الخلفية مع الاسترجاع التلقائي.
- `apps/services_app`: الخدمات الرقمية وعروض الأسعار المخصصة (Custom Quotes).
- `apps/notifications`: التحقق من القنوات وبث إيصالات العمليات الناجحة.
- `apps/audit`: سجل تتبع وتدقيق إجراءات المشرفين.
- `apps/telegram_bot`: محرك بوتات التليجرام (aiogram 3) ومعالجات مجموعة المشرفين.
